# 文本差异对比工具 Pro

在线文本差异对比工具，支持双栏对比和统一视图，类 diffchecker 体验，纯本地处理。

## 功能特性

- 🔍 **双栏对比** — 原始文本和修改文本并排显示，直观对比
- 📄 **统一视图** — Git diff 风格的单栏差异视图
- ⚡ **快速对比** — 基于 Myers 算法的实时差异计算
- 📝 **单词级高亮** — 精确到单词级别的差异标注
- 🔢 **行号显示** — 每行标注行号，方便定位
- 📥 **导出报告** — 差异结果可导出为文本文件
- 🔄 **一键交换** — 快速交换左右文本
- 🎲 **示例数据** — 内置 API 文档对比示例
- 🛡️ **纯本地处理** — 所有计算在浏览器完成，不联网

## 使用方式

### 在线使用（推荐）

访问部署页面即可使用。

### 本地使用

1. 下载 `index.html` 文件
2. 双击用浏览器打开
3. 在左侧粘贴原始文本，右侧粘贴修改文本
4. 点击「开始对比」

## 对比模式

### 双栏对比（Side by Side）
原始和修改后的文本并排显示，删除行和新增行分别高亮。

### 统一视图（Unified）
类似 `git diff` 输出格式，适合查看代码或配置文件的变更。

## 适用场景

- 代码审查：对比代码修改前后的差异
- 文档审校：查看文档版本之间的修改
- 配置文件对比：快速发现配置差异
- 翻译校对：对比原文和译文的差异
- 学生作业：对比论文草稿和终稿

## 技术栈

纯 HTML/CSS/JavaScript，Myers 差分算法 + LCS 单词级差分，零外部依赖。
